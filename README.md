# 🌲 全国 林業・木材デイリーニュース (Forestry & Timber Daily)

全国の林業、木材産業、森林政策、木造建築に関する最新ニュースを毎日自動巡回収集し、さっと読める「3つの要約ポイント」とともに日別アーカイブとして閲覧できる**完全無料**のオンラインニュースリーダーです。

🌐 **公開WebサイトURL**:  
👉 **[https://kojiro-nakamura.github.io/ringyo-news/](https://kojiro-nakamura.github.io/ringyo-news/)**

スマートフォン・タブレット・PCのブラウザから、いつでもアクセスできます（スマホの「ホーム画面に追加」やブックマーク推奨）。

---

## 🌟 主な特徴

1. **完全無料・サーバー代0円**
   - **GitHub Pages** による高速静的Web配信。
   - ニュース収集元には **Google News RSS** を使用（有料API契約不要）。
   - Google Newsの暗号化URLから **本来の元記事URLを自動復元**。
   - 記事メタデータと本文から **「30秒で読める要点まとめ」** を自動生成。
   
2. **PCの電源を切っていても毎日自動巡回・更新**
   - **GitHub Actions** により、毎日 **06:00, 12:00, 18:00 (JST)** に自動で最新ニュースを取得・要約・コミット。
   - あなたのPCを起動しておく必要は一切ありません。

3. **日ごとにデータベースへ蓄積（過去にさかのぼって閲覧可能）**
   - 収集されたニュースは日別のJSONアーカイブとしてリポジトリ内に永続保存されます。
   - 左サイドバーの **日別一覧** や **カレンダー（日付ピッカー）** から、いつでも過去の日付にさかのぼって当時の林業ニュースを振り返ることができます。

4. **林業・木材産業に特化したカテゴリ分類**
   - 「林政・施策」: 林野庁、森林環境税、補助金、計画、自治体施策
   - 「建築・木材利用」: 木造ビル、CLT、中高層木造、公共建築物木造化、木質空間
   - 「流通・市場」: 原木価格、木材市場、輸出入、製材、合板、流通
   - 「スマート林業・技術」: ドローン、高性能林業機械、ICT、自動化、安全、バイオマス
   - 「森林管理・地域」: 間伐、造林、再造林、森林組合、治山、J-クレジット、花粉対策
   - 「業界・一般」: その他林業全般

5. **UDフォント採用で圧倒的な読みやすさ**
   - 本文・要約には公共機関でも推奨される **BIZ UDPゴシック** を採用。
   - タイトル・ロゴには上品でモダンな **しっぽり明朝**、**Zen角ゴシック**、**Outfit** をハイブリッド適用。

## 🛠️ プロジェクト構成

```
ringyo-news/
├── .github/workflows/
│   └── daily_news.yml   # 毎日3回自動実行されるGitHub Actions
├── docs/                # GitHub Pagesとして公開されるWebサイト本体
│   ├── index.html       # ニュースリーダーUI
│   ├── style.css        # スタイルシート（森林グリーン ✕ ウッドアンバー）
│   ├── app.js           # カレンダー操作・検索・描画ロジック
│   ├── favicon.svg      # 針葉樹・木材グラデーションの特製ファビコン
│   ├── favicon.png
│   ├── apple-touch-icon.png
│   └── data/            # 蓄積されるJSONデータベース
│       ├── index.json   # 日付一覧と統計
│       ├── search_index.json
│       └── dates/       # 各日のニュースデータ (YYYY-MM-DD.json)
└── build_site.py        # ニュース収集＆静的サイトビルダー
```
